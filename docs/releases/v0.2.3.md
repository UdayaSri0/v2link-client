# v2link-client v0.2.3

This corrective patch release supersedes v0.2.2 without moving or reusing its
existing tag. It carries forward the bundled Xray-core hardening and the guarded
manual release workflow now present on the default branch.

Official x86-64 AppImage and Debian packages continue to bundle Xray-core
v26.3.27, `geoip.dat`, `geosite.dat`, the MPL 2.0 license, and an exact version
record. The release workflow builds and verifies the artifacts from the selected
default-branch commit before any publication step.

There are no profile, settings, or database migrations in this corrective release.
Upgrade by replacing the prior AppImage or installing the new `.deb`; existing user
data is retained. GitHub source archives are not installable binary packages.
