# v2link-client v0.2.2

This patch release hardens the bundled Xray-core path. Official x86-64 AppImage and
Debian/APT packages include Xray-core v26.3.27, `geoip.dat`, `geosite.dat`, the MPL
2.0 license, and an exact version record; no separate Xray installation is required.

Xray downloads are pinned to official XTLS release assets and verified by SHA-256
before extraction. Builds validate the executable version, and release verification
extracts both final artifacts and runs an offline `xray run -test`.

Developers running from source can use `./scripts/dev_run.sh`, which prepares the
pinned native Xray copy once. Set `V2LINK_SKIP_XRAY_FETCH=1` to require a manual fetch.

Diagnostics now report the selected source, path, version, architecture, geo assets,
asset directory, and version-manifest status. Xray Settings includes an offline
installation self-test and reset-to-default action.

Official artifacts currently target x86-64. ARM64 source support remains available,
but ARM64 packages are deferred until native build-and-verification CI is provided.

Upgrade by replacing the prior AppImage or installing the new `.deb`. Existing
profiles and settings are retained. GitHub source archives are not installable binary
packages.
